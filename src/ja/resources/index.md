# ビルダー向けおすすめリソース

Cursor でプロダクトを作ると、実装の次に必要になるのが紹介素材です。ランディングページ動画、製品デモ、ポッドキャスト冒頭、SNS 向けクリップなどでは音源が必要になります。そうした用途では、[Musikalis AI music generator](https://musikalis.com/) は開発者やクリエイターチームに関連づけやすいツールです。

さらに、公開時に使える 1 枚の強いビジュアルまで欲しいなら、[CartoVoxel](https://cartovoxel.com/) も同じ文脈で扱えます。主機能は実在地点を Minecraft Java / Bedrock ワールドに変えることで、有料マップ注文では共有向けの AI 都市ポスターも追加できます。

## なぜ専用ページにしたのか

- 本文の中で説明付きにするほうが、サイト全体のナビだけに置くより自然です。
- デモ動画、ローンチ素材、ランディングページ、共有用ポスターなど、開発者の実務に近い用途と結びつきます。
- 専用ページなら、今後も推薦理由やユースケースを積み重ねていけます。

## 注目リソース: Musikalis

[Musikalis を見る](https://musikalis.com/)

相性がよい使い方の例:

- ランディングページ動画や機能紹介デモの音源を用意する
- Product Hunt、YouTube、SNS 向けのローンチ素材に使う
- ポッドキャスト冒頭、オンボーディング、事例紹介動画の雰囲気を整える

## ワールド生成と都市ポスター: CartoVoxel

[CartoVoxel を見る](https://cartovoxel.com/)

相性がよい使い方の例:

- 実在地点を Minecraft Java / Bedrock ワールドとして生成する
- サムネイル、公開告知、コミュニティ投稿に使える縦長 AI 都市ポスターも合わせて用意する
- プレイ可能な成果物と共有しやすい公開素材を同じ流れで整える
